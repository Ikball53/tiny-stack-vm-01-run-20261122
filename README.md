# Tiny Stack VM

A compact Node implementation of make.fun's tiny stack ISA: wrapping 32-bit arithmetic, a 256-value data stack, calls, 256 words of memory, byte input and output, and all ten traps with their exact exit codes. The repository holds only a tiny loader; the VM itself is supplied as an entry secret and runs every instance of the set in one pass.
